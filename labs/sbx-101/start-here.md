# Start here

Welcome to SBX 101. In this lab you will run an AI coding agent inside a Docker Sandbox — you'll create the sandbox, prove its isolation is real, control what the agent can reach on the network, hand it tools, build and harden something it writes for you, and package the whole setup so a team can reuse it. Everything runs in your browser, every command is the real command surface, and there is nothing to install.

The lab explains itself in two voices, covering the same steps with the same commands. You can change your pick at any time by returning to this page.

**Track A** is written for people who are comfortable with Docker and the terminal. Explanations stay short and technical — kernels, mount tables, and CVEs come up without pausing to define them.

**Track B** is written for people who aren't. It walks the same steps, but each one opens with what it means and why it matters, explained in everyday language rather than technical terms.
